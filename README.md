## Проект

- реализует базовые классы для описания товаров и категорий.

## Какие технологии использованы?

- Python (версия >= 3.10)
- Poetry (для управления зависимостями)
- Pytest (для написания тестов)
- Flake8 (для соблюдения стандартов оформления кода)

## Функциональность

- Класс `Product`:
  - строковое представление: `Название продукта, X руб. Остаток: Y шт.`;
  - магический метод сложения `__add__`, возвращающий суммарную стоимость двух товаров (`price * quantity` для каждого);
  - складывать можно только продукты одного класса (например, `Smartphone` + `Smartphone`), иначе выбрасывается `TypeError`.
- Классы-наследники `Product`:
  - `Smartphone` (доп. атрибуты: `efficiency`, `model`, `memory`, `color`);
  - `LawnGrass` (доп. атрибуты: `country`, `germination_period`, `color`).
- Класс `Category`:
  - строковое представление: `Название категории, количество продуктов: X шт.`, где X — общая сумма `quantity` всех товаров категории;
  - метод `add_product` принимает только `Product` и его наследников (иначе `TypeError`);
  - геттер `products` возвращает список товаров с использованием строкового представления `Product`.

## Как начать работу?

1. Склонируйте репозиторий:
   `git clone <url-репозитория>`

2. Установите зависимости (если используется Poetry):
   `poetry install`

3. Запустите тесты:
   `pytest`

4. Сформируйте отчет о покрытии тестами:
   `pytest --cov=src --cov-report=term > coverage_report.txt`

   В результате в корне проекта появится файл `coverage_report.txt` с данными о покрытии.
