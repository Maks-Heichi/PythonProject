## Проект

- реализует базовые классы для описания товаров и категорий.

## Какие технологии использованы?

- Python (версия >= 3.10)
- Poetry (для управления зависимостями)
- Pytest (для написания тестов)
- pytest--cov (отчёт о покрытии тестами)
- Flake8 (для соблюдения стандартов оформления кода)

## Функциональность

- Абстрактный базовый класс `BaseProduct`:
  - общая функциональность для всех продуктов (цена, сложение, валидация);
  - абстрактный метод `__str__`, реализуемый в наследниках.
- Класс-миксин `ReprMixin`:
  - при создании объекта выводит в консоль имя класса и переданные параметры (например, `Product('Продукт1', 'Описание продукта', 1200, 10)`);
  - добавлен в цепочку наследования класса `Product`.
- Класс `Product` (наследует от `ReprMixin` и `BaseProduct`):
  - строковое представление: `Название продукта, X руб. Остаток: Y шт.`;
  - при создании с нулевым количеством выбрасывается `ValueError` с сообщением «Товар с нулевым количеством не может быть добавлен»;
  - магический метод сложения `__add__`, возвращающий суммарную стоимость двух товаров (`price * quantity` для каждого);
  - складывать можно только продукты одного класса (например, `Smartphone` + `Smartphone`), иначе выбрасывается `TypeError`.
- Классы-наследники `Product`:
  - `Smartphone` (доп. атрибуты: `efficiency`, `model`, `memory`, `color`);
  - `LawnGrass` (доп. атрибуты: `country`, `germination_period`, `color`).
- Абстрактный базовый класс `BaseProductEntity`:
  - общая функциональность для `Category` и `Order`;
  - абстрактные методы `__str__` и свойство `name`.
- Класс `Category` (наследует от `BaseProductEntity`):
  - строковое представление: `Название категории, количество продуктов: X шт.`, где X — общая сумма `quantity` всех товаров категории;
  - метод `add_product` принимает только `Product` и его наследников (иначе `TypeError`);
  - метод `average_price()` — подсчёт среднего ценника (сумма цен товаров / количество товаров); при пустой категории возвращает 0;
  - геттер `products` возвращает список товаров с использованием строкового представления `Product`.
- Класс `Order` (Заказ, наследует от `BaseProductEntity`):
  - ссылка на товар (`product`), количество (`quantity`), итоговая стоимость (`total_cost = price * quantity`);
  - в заказе только один товар;
  - строковое представление: `Заказ: Название, количество: X шт., итого: Y руб.`

## Как начать работу?

1. Склонируйте репозиторий:
   `git clone <url-репозитория>`

2. Установите зависимости (если используется Poetry):
   `poetry install`

3. Запустите тесты:
   `pytest`
